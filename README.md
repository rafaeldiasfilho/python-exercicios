# Exercícios de Python

Exercícios dos meus primeiros estudos de Python.

| Pasta | O que é |
|---|---|
| `sistema-de-cadastro/` | Sistema de cadastro de produtos com interface feita em CustomTkinter e opção de tema claro ou escuro |
| `interface-de-cadastro/` | Primeira versão do cadastro de produtos, feita com Tkinter |
| `fundamentos/` | Operações básicas: tipos de dados, conversões e operadores matemáticos |

## Como rodar

```bash
pip install -r requirements.txt
python sistema-de-cadastro/app.py
```
